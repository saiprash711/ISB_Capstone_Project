## 🚀 How to Use

### Presenting the Deck
1. Open `Daikin_EDA_Dashboard_Presentation.pptx`
2. Press **F5** for full-screen presentation mode
3. Navigate with arrow keys or click
4. Use Presenter View for notes (if added)

### Customizing
1. Edit text directly in PowerPoint
2. Replace placeholder images with actual screenshots
3. Update statistics to match your latest data
4. Add your contact information on final slide
5. Customize colors via Format → Shape Fill/Line

### Adding Screenshots
To enhance the presentation with actual dashboard screenshots:
1. Run the dashboard: `streamlit run dashboard.py`
2. Take screenshots of each page
3. Insert into corresponding slides
4. Recommended size: 5-6 inches wide for detail visibility
