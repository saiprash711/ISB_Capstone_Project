## Setup

- **Holdout:** billing for 2024-07-01 to 2025-06-30 (`2024 July to 2025 June.xlsx`). It was never used for training, model design or tuning.
- **Training data:** history up to 2024-06-30.
- **Engine:** the production engine (`ModelSelector.select_and_fit`, the same code the dashboard runs), run per SKU × branch on weekly ODU demand.
- **Benchmarks:** same week last year (seasonal naive) and the 4-week moving average.
- **Accuracy:** 100% − WAPE. It is negative when absolute errors exceed actual volume.

## Product lifecycle

SKUs sold before Jul-2024 fell from 467,882 units in the prior 52 weeks to 375,509 in FY24-25 (-19.7%). Meanwhile, 39 new-launch SKUs sold 68,765 units. No model built on a SKU's own history can anticipate this substitution. Forecasts for old SKUs therefore run high, and launch volume is missing until a new SKU has about 5 weeks of sales. Totals against all billed demand show the net effect a planner sees.
