STEP 1: Install Required Libraries
───────────────────────────────────────────────────────────────────────────────
Open your terminal/command prompt and run:

    pip install statsmodels scikit-learn

This installs the forecasting models needed for the new feature.

STEP 2: Verify Installation
───────────────────────────────────────────────────────────────────────────────
Check that everything is installed correctly:

    python verify_installation.py

You should see ✅ marks for all libraries.

STEP 3: Run the Dashboard
───────────────────────────────────────────────────────────────────────────────
Launch the upgraded dashboard:

    streamlit run dashboard.py

Or use the batch file:

    run_dashboard.bat

STEP 4: Try the New Feature
───────────────────────────────────────────────────────────────────────────────
1. In the sidebar, click "🎯 Demand Forecasting"
2. Select a SKU from the dropdown
3. Choose Statistical or ML model
4. Click "🚀 Run Forecast"
5. View results and download!
