🎯 Core Feature Engineering Rationale for ISB Defense

  • Moving Run-Rate Anchor (33.0%): rolling_mean_4 acts as the demand anchor, shielding the model from random 1-week dealer invoicing anomalies.
  • Volatility Variance Dampener (28.5%): rolling_std_4 directly informs predictive confidence intervals and captures sudden weather-driven cooling spikes.
  • Dealer Replenishment Harmonics (16.8%): Lag 2 and Lag 4 capture the bi-weekly and monthly distributor replenishment rhythm across Tamil Nadu, Karnataka, Telangana, and Kerala.
  • Quarterly Macro Trend (15.1%): rolling_mean_12 and Lag 12 capture macro seasonal transitions (e.g. pre-summer dealer loading vs monsoon lull).
  • Exogenous Catalysts: Festival Flag (Diwali, Pongal, Onam) and Promotion Flag (pre-season dealer schemes) prevent under-forecasting during key retail schemes.

🌲 Random Forest Regressor

Machine Learning

Ensemble of de-correlated decision trees with recursive MSE variance reduction.

ŷ(x) = (1/B) Σ_{b=1}^B T_b(x)
  • Feature Space: 13-dimensional vector (Lags 1/2/4/12, Rolling Mean 4W/12W, Rolling Std, Month, Quarter, Branch, Segment, Festival, Promo)
  • Hyperparameters: n_estimators=100, max_depth=10, min_samples_split=4, max_features='sqrt'
  • Splitting Metric: Mean Squared Error (MSE) / Variance Reduction
  • Key Strength: Captures non-linear heatwave surges and dealer scheme step-functions without multicollinearity failure.

📈 SARIMAX (1,1,1)(1,1,1)₁₂

Seasonal Time-Series

Seasonal Autoregressive Integrated Moving Average with exogenous promotional regressors.

Φ_P(Bˢ)φ_p(B)(1-B)ᵈ(1-Bˢ)ᴰ y_t = Θ_Q(Bˢ)θ_q(B)ε_t + Σ β_k X_{k,t}
  • Order Spec: Non-seasonal (p=1, d=1, q=1), Seasonal (P=1, D=1, Q=1), Seasonal cycle s=12 weeks
  • Exogenous Regressors (X_t): Festival Flag and Dealer Pre-Season Scheme Indicator
  • Stationarity Check: Augmented Dickey-Fuller (ADF) Unit Root Test (p < 0.05 confirmed post differencing)
  • Residual Check: Ljung-Box Q Test verifies white noise residuals ε_t ~ WN(0, σ²) without autocorrelation.

📉 Holt-Winters Exponential Smoothing

Triple ETS

State-space level, trend, and seasonal smoothing decomposition.

ℓ_t = α(y_t - s_{t-m}) + (1-α)(ℓ_{t-1} + b_{t-1})
b_t = β(ℓ_t - ℓ_{t-1}) + (1-β)b_{t-1}
s_t = γ(y_t - ℓ_{t-1} - b_{t-1}) + (1-γ)s_{t-m}
  • Smoothing Weights: Level α ≈ 0.28, Trend β ≈ 0.05, Seasonal γ ≈ 0.42
  • Cycle Length: m = 12 weeks (quarterly cyclicality)
  • Key Strength: Extremely fast compute, zero matrix inversion required, ideal for real-time edge replenishment.

🎯 ARIMA (1,1,1)

Linear Baseline

Classical Box-Jenkins linear un-seasonal benchmark model.

(1 - φ_1 B)(1 - B) y_t = c + (1 + θ_1 B) ε_t
  • Parameters: AR(1) autoregressive φ_1, MA(1) moving average θ_1, First Differencing d=1
  • Estimation Method: Maximum Likelihood Estimation (MLE) with Conditional Sum of Squares
  • Role in Capstone: Serves as the Standard Operational Baseline, proving the quantifiable accuracy gain of ML feature engineering.
